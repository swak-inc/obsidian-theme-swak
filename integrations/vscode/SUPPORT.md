# Support / サポート

Report bugs and feature requests through [GitHub Issues](https://github.com/swak-inc/obsidian-theme-swak/issues). This repository also hosts the Obsidian theme, so include **Swak Markdown** in the title.

不具合・要望は [GitHub Issues](https://github.com/swak-inc/obsidian-theme-swak/issues) へ。Obsidianテーマと共通のリポジトリなので、件名に **Swak Markdown** を入れてください。

Include the following information. / 次の情報を添えてください。

- Extension version / 拡張のバージョン
- Editor name and version, OS / エディター名・バージョン・OS
- Reproduction steps and expected behavior / 再現手順と期待する動作
- A minimal Markdown example and screenshot / 最小構成のMarkdownとスクリーンショット

Remove private documents, personal information, credentials, and local paths from public reports. For private security reports, contact [info@swak.jp](mailto:info@swak.jp).

公開する報告からは、非公開文書・個人情報・認証情報・ローカルパスを除いてください。非公開で伝える必要があるセキュリティ報告は [info@swak.jp](mailto:info@swak.jp) へお願いします。
